# Akrasia Command Deck (prototipo Three.js)

Prototipo de la portada como sala de mando 3D: núcleo Λ holográfico de partículas, muro curvo de vídeos con reflejos, servicios en órbita, columnas de datos, cursor holográfico con onda en el suelo, bloom + lente y sonido de interfaz opcional (Web Audio).

- Página única: `index.html` (Three.js 0.160.0 desde jsDelivr mediante importmap).
- Espera `media/demo-*.mp4` e `img/logo.svg` junto a la página. Los clips son DEMO ficticios (`public/media`).
- El chat está simulado; la integración en Astro conectará el chat real, los proyectos publicados y una versión ligera para móviles poco potentes y "movimiento reducido".
